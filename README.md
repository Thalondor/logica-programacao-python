# Exercícios de Lógica de Programação em Python

Repositório com algoritmos desenvolvidos durante o curso de Análise e Desenvolvimento de Sistemas (USF), com foco na prática de estruturas de dados básicas e raciocínio lógico sem uso de bibliotecas externas.

## Arquivos do Projeto

* **`contar_caractere_recursivo.py`**: Função recursiva que percorre uma string e contabiliza quantas vezes um caractere específico aparece (sem distinção entre maiúsculas e minúsculas).
* **`menor_valor_recursivo.py`**: Algoritmo recursivo que recebe uma sequência numérica digitada pelo usuário, identifica e imprime o menor valor da lista.
* **`analise_matriz_4x4.py`**: Programa que preenche uma matriz 4x4 com as entradas do usuário, exibe os valores formatados e calcula a soma total, a média e as somas dos elementos acima e abaixo da diagonal principal.

## Tecnologias
* Python 3
